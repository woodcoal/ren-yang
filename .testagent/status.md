# 灵魂保存即生效测试状态

## 结论

人物和世界创建即启用、灵魂保存即生效、AI 与历史只回填、旧草稿迁移和分层边界均已有自动化证据。源码类型检查、生产构建和浏览器主流程通过。

## 需求与证据

| 需求 | 自动化证据 |
|---|---|
| 创建对象立即形成当前版本并默认启用 | `创建人物和世界时初始灵魂立即成为当前版本且对象默认启用` |
| 保存生成不可变历史并切换当前版本 | `保存灵魂立即生成不可变历史并切换当前版本` |
| AI 与历史只回填，保存后才生效 | `灵魂直接编辑，AI 与历史只回填文本且保存后才生效` |
| 列表取消设定状态 | `人物与世界列表移除设定状态且默认每页十项并保留启停确认` |
| 旧草稿提升为当前历史 | `保存即生效迁移保留旧版本并把现有草稿提升为当前历史版本` |
| 保存与审计同一事务 | `灵魂保存和永久删除与对应审计记录在同一 SQLite 事务中完成` |
| Token 上限与超限失败原子性 | `创建和保存灵魂在 Token 上限内成功且超限时不产生版本` |
| 历史版本不得跨对象串用 | `保存灵魂拒绝使用其他对象的历史版本且不改变当前版本` |
| 真实页面闭环 | Playwright `首次设置、灵魂保存、文档确认及三格式导出形成可复现闭环` |
| 控制器不得跨层 | `tests/architecture/layering.test.ts` |
