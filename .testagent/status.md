# 灵魂单文本模型测试状态

## 结论

灵魂单文本、可选 AI 整理、草稿发布边界、历史版本、快捷创建、运行上下文和旧库迁移均已有自动化证据。全量测试与生产构建通过。

## 需求与证据

| 需求 | 自动化证据 |
|---|---|
| 灵魂只保存一段 `promptText` | `灵魂单文本迁移保留旧运行摘要并移除旧结构字段`；共享 Schema 类型检查通过 |
| 新建和修改使用单一大文本输入 | `灵魂使用单文本弹窗，可选择原文保存或自动分析且不会直接发布` |
| 手动模式不改写正文 | `手动保存灵魂只移除首尾空白且不调用模型` |
| AI 整理只保存草稿 | `自动分析把模型整理结果保存为未发布草稿` |
| AI 整理不得增加事实 | `灵魂自动分析只允许整理表达并要求单文本结果` |
| AI 失败不覆盖草稿 | `自动分析不可用或输出无效时不覆盖原草稿` |
| 草稿、发布和历史版本保留 | `无资料创建原创人物，草稿发布后不可变且历史版本只能复制为新草稿` |
| 快捷创建输出单文本灵魂 | `从自然语言和选定资料生成不落库的结构化人物候选草稿`；`从自然语言生成不落库的结构化世界候选草稿` |
| 生成与分析读取单文本灵魂 | `保存固定输入与证据快照并完成结构化兴趣判断`；`模型分析只形成待审核提案，人工接受后才创建有效成长` |
| 旧数据无损迁移 | `灵魂单文本迁移保留旧运行摘要并移除旧结构字段`；真实数据库只读备份副本迁移后完整性为 `ok`、外键违规为 0 |
