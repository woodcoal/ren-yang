# 灵魂单文本模型测试计划

1. 数据模型与迁移
   - 验证旧 `runtime_summary` 迁移后等于新 `prompt_text`。
   - 验证草稿发布、历史复制和 Token 超限仍正确。
2. 手动与 AI 整理
   - 验证手动输入只做首尾规范化并形成未发布草稿。
   - 验证 AI 整理返回纯文本、保存草稿且不切换当前版本。
   - 验证模型未配置或输出无效时不保存草稿。
3. 前端交互
   - 验证一个大文本输入框、自动分析复选框和草稿确认发布流程。
   - 验证历史版本仍可复制为草稿。
4. 运行上下文
   - 验证快捷创建、兴趣判断、图文生成和分析只使用 `promptText`。
5. 门禁
   - 运行定向测试、全量测试、生产构建和迁移完整性检查。

## 2026-08-30 灵魂保存即生效增量计划

1. 状态机与迁移
   - `创建人物和世界时初始灵魂立即成为当前版本且对象默认启用`
   - `保存灵魂立即生成不可变历史并切换当前版本`
   - `保存即生效迁移把现有草稿提升为当前历史版本`
2. 灵魂编辑器
   - `灵魂直接编辑，AI 与历史只回填文本且保存后才生效`

3. 列表简化
   - 扩展列表测试，断言不再显示设定状态、待确认统计或待确认创建文案。
4. 架构与门禁
   - 验证控制器只调用 `SoulApplicationService`，仓储原子写入版本与当前指针。
   - 运行定向 Vitest、全量测试、直接 TypeScript 检查、Nuxt 构建和迁移完整性检查。
5. 缺口补强
   - `创建和保存灵魂在 Token 上限内成功且超限时不产生版本`
   - `保存灵魂拒绝使用其他对象的历史版本且不改变当前版本`
