# 快速创建交互与提示词纯化

## 问题

- 人物创建入口依赖页面侧点击更新弹窗状态，没有使用 Nuxt UI 模态框的原生触发契约。
- AI 生成可能持续数十秒，原界面只显示提交按钮加载，容易被误判为卡死。
- 候选和未发布说明被写进模型系统提示，导致模型把创建流程元话术复制到运行摘要。

## 调整

- 创建按钮改为 `UModal` 默认插槽触发器，由模态框直接管理打开交互。
- 提交后弹窗切换为独占内容的等待页，显示旋转图标、当前阶段、等待说明和后续去向；期间禁止关闭与重复提交。
- 人物和世界草稿提示改为“只描述业务对象”，不再向模型复述当前候选状态。
- 共享 Schema 拒绝在摘要和章节中出现候选草稿、待用户确认、尚未发布或不代表已影响等流程说明；模型输出命中时按现有结构化输出机制自动重试。
- 提示词契约版本升级为 `artifact-v6`。

## 验证

- 创建人物和世界按钮必须能打开自然语言弹窗。
- 处理中只显示等待页，不显示可重复提交的编辑表单。
- 第一次返回流程元话术时必须触发第二次模型调用，最终草稿不含相关短语。
- `pnpm vitest run tests/components/content-forms.test.ts tests/components/subject-list-creation.test.ts tests/unit/prompt-builder.test.ts tests/integration/generation-run.test.ts --reporter=verbose`：4 个测试文件、37 个测试通过。
- `pnpm test`：36 个测试文件、174 个测试通过。
- `pnpm build`：Nuxt 客户端、服务端和 Nitro 生产构建通过。
