# AI 模型与固定算法配置开发记录

## 调整目标

支持多个不同端点和不同模型组合执行灵魂、成长处理；API Key 加密存入 SQLite，本地主密钥不入库；算法流程固定在代码中，管理员只配置步骤使用的模型与参数。

## 完成内容

### 1. AI 接口与模型部署

- 新增 `ai_connections`，保存 OpenAI-compatible 端点、启用状态和 AES-256-GCM API Key 密文；
- 新增 `ai_model_deployments`，一个连接可登记多个文本或图片模型；
- 新增脱敏查询、创建、编辑和文本模型真实最小检测接口；
- 编辑连接时不回填密钥，省略新密钥即保留原密文；审计不包含密文或明文。

### 2. 固定算法与版本化配置

- 代码固定人物灵魂、世界灵魂、人物成长、世界成长四个算法；
- 灵魂算法只有 `organize` 步骤，成长算法固定 `extract`、`synthesize` 两步；
- 新增算法配置版本与步骤配置表，每次保存发布完整新版本；
- 数据库只能绑定文本模型部署、固定提示词编码和温度、输出 Token、超时，不能新增、删除或调整步骤顺序；
- 运行时按步骤动态创建模型端口，支持同一算法组合不同连接和模型。

### 3. 成长处理链

- 增加人物/世界成长原子提取和综合编译提示词；
- 提取结果必须包含结论、证据输入 UUID 和置信度；
- 程序校验证据引用、合并重复结论并计算实际证据数后，才允许综合；
- 综合结果继续保存为不生效的学习提示词草稿，由管理员检查、编辑和发布；
- 分析批次保存算法实现、配置、连接、模型部署、提示词版本和参数的非敏感快照。

### 4. 管理界面

- 新增 `/ai-models`：编辑接口、加密凭据状态和具体模型部署；
- 新增 `/ai-algorithms`：按固定步骤选择文本模型和调整参数并发布版本；
- 系统 AI 设置中的内容分析说明收敛为人物记忆，灵魂和成长参数转移到算法配置。

## 安全与兼容

- 继续使用既有 HKDF 派生标识，避免升级后已有的人物账号密文失效；
- API Key 只在连接检测或算法执行期间临时解密到内存；
- 备份包含数据库密文但不包含本地主密钥，恢复必须使用相同密钥；
- 旧图文生成与人物记忆仍使用原环境模型链路，本轮不扩大迁移范围；独立应用服务测试未注入算法时保留原兼容路径。

## 验证范围

- 数据库从空目录迁移及从 `0000` 结构升级；
- 密钥加密、编辑保留、脱敏响应和执行期解密；
- 算法配置连续发布、快照无密钥和动态模型选择；
- 两阶段成长的证据校验、重复结论合并、草稿不自动生效；
- AI 模型与算法页面提交行为及导航入口。
