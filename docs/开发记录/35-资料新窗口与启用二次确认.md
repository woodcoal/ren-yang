# 资料新窗口与启用二次确认

## 调整范围

- 人物和世界详情页的资料卡改为在浏览器新标签页打开资料详情，并增加 `noopener noreferrer` 安全隔离。
- 人物、世界和资料列表的批量启用操作增加二次确认；确认前不发送状态更新请求。
- 人物、世界和资料详情页的单项启用操作增加二次确认。
- 人物和世界资料选项卡中的资料启用操作增加二次确认，禁用与解除关联确认逻辑保持不变。
- 本次“所有资料”仅指全局资料实体；人物成长反馈资料、记忆记录和世界成长资料属于各自工作区的局部参与状态，不在本次调整范围内。

## 交互结果

- 点击人物或世界资料卡的正文区域后，原详情页保持不变，资料详情在新标签页打开。
- 点击单项或批量启用后先显示对象名称或数量，用户选择“确认启用”后才执行请求。
- 请求失败时保留确认弹窗或页面错误提示，不把失败操作显示为成功。

## 验证结果

- 定向测试：4 个文件、17 项测试通过。
- 全量测试：37 个文件、194 项测试通过。
- `pnpm build` 生产构建通过。
- `git diff --check` 对本次变更文件检查通过。
- `pnpm typecheck` 仍在读取项目源码前被 TypeScript 7.0.2 与 vue-tsc 3.3.11 的包导出兼容问题阻断，错误为 `ERR_PACKAGE_PATH_NOT_EXPORTED: ./lib/tsc`；本次变更未引入该工具链问题。

- `批量启用与禁用资料均需二次确认`：验证资料列表确认前不请求、确认后才更新。
