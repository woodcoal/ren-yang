# 成长记忆事实模型与后台管理

## 1. 完成范围

- 新增世界资料成长启用状态，禁用只影响下一次分析，不改变已确认成长。
- 新增人物反馈资料，支持人工创建、按条展示、批量启用、批量禁用和批量删除。
- 新增世界与人物共用的成长记录、不可变修订和来源证据链。
- 新增人物处理记录、记忆记录、不可变记忆修订和处理证据关系。
- 成长与记忆统一使用 `candidate`、`active`、`superseded`、`archived`、`rejected` 状态。
- 人工创建成长时只形成候选，必须由管理员确认后才能生效。
- 运行成功后自动写入人物处理记录；同一运行通过唯一约束只保留一条记录。
- 人物记忆可以显式复制为人物反馈资料，不直接形成成长。
- 人物与世界后台的成长、记忆说明卡片替换为真实列表、创建表单和批量操作栏。
- 控制器只调用 `LearningApplicationService`，应用服务只通过 `LearningRepository` 访问 SQLite。

## 3. 状态和删除规则

成长与记忆当前允许的人工转换：

```text
candidate → active
candidate → rejected
active → archived
archived → active
```

重复提交当前目标状态按幂等操作处理。跨人物、跨世界或非法状态批次整批拒绝，不允许部分成功。

人物反馈资料删除时：

1. 核对全部条目属于当前人物；
2. 把已有成长证据标记为“来源不可用”；
3. 删除反馈资料正文和业务行；
4. 保留已确认成长及证据摘要。

当前阶段人物反馈资料尚未投影到 OpenViking，因此不存在远端副本时直接完成本地删除。OpenViking Resource 投影、两阶段远端删除和分析批次正文清除在下一阶段统一接入，不以虚假同步状态提前展示。
