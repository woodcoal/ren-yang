# 人物世界资料选项卡与全屏创建等待开发记录

日期：2026-08-30

## 目标

- 人物和世界详情页使用相同的“资料”选项卡与操作逻辑。
- 已关联资料以卡片展示，解除关联必须二次确认，且不删除资料正文。
- 用户可在当前对象内直接新建文本或批量文件资料，新资料自动关联当前对象。
- 用户可模糊搜索尚未关联的已有资料，一次选择多项加入当前对象。
- 人物和世界快速创建提交后使用最高层全屏加载遮罩，避免长时间 AI 请求被误认为页面卡死。

## 实现边界

本次未新增数据库、应用服务或控制器能力。页面继续调用既有资料创建、关联、解除和列表接口；控制器、服务层与数据层分层关系未变化。

新增统一组件 `SubjectSourceManager`，职责包括：

- 接收当前对象已关联资料及系统全部资料；
- 过滤已关联项，并使用资料名称和正文摘要进行模糊搜索；
- 以标签选择器一次选择多项已有资料；
- 承载 `SourceImportForm`，把粘贴文本或多文件导入意图交给详情页；
- 在解除关联前显示当前对象和资料名称，用户确认后才发出解除事件。

人物详情新增独立“资料”标签，原“世界与资料”管理区改为“基本信息与管理”。世界详情的“世界资料”标签统一改为“资料”。两类详情页分别把新资料固定关联到当前人物或世界，忽略资料表单中不存在的其他对象选择。

`QuickCreateSubjectModal` 在人物或世界生成请求进行期间，通过 `Teleport` 把固定定位遮罩挂到页面根节点，使用 `z-[9999]`、加载旋转动画和等待文案覆盖全部后台内容。请求完成或失败后遮罩自动移除；失败时原自然语言输入仍保留。
