# 资料状态、分页与标签关系管理

## 目标

- 为普通资料增加全局启用和禁用状态。
- 资料列表改为服务端分页，默认每页 10 项。
- 导入和详情统一使用可搜索、多选、可移除的关联对象标签。
- 支持当前页批量禁用，并要求所有禁用操作二次确认。

## 实现

### 数据与检索

- `source_materials` 新增 `is_enabled INTEGER NOT NULL DEFAULT 1`。
- 迁移旧数据时全部设为启用，不修改原正文、切片和关系。
- 禁用资料不进入管理端 FTS5、人物任务 SQLite 检索和 OpenViking 投影。
- 禁用后异步删除 OpenViking 投影，重新启用后从 SQLite 恢复投影。
- `world_sources.is_enabled` 仍只表示资料是否参与指定世界的成长分析，与普通资料全局状态相互独立。

### 接口

- `GET /api/v1/sources/page?page=1&pageSize=10`：返回稳定排序的分页资料。
- `PATCH /api/v1/sources/{sourceId}/status`：修改单项资料状态。
- `PATCH /api/v1/sources/status`：原子修改最多 100 项资料状态。
- 批量状态修改先验证全部资料存在，再执行单条 SQLite 更新，之后为每项资料创建独立同步任务。

### 管理界面

- 分页数量固定为 5、10、20、50、100，默认 10；页码与数量保存在 URL。
- 当前页只允许勾选已启用资料；切换分页后清空选择。
- 列表提供批量禁用，不提供行内单项禁用按钮；批量禁用必须二次确认。
- 资料详情提供单项启用和禁用；禁用必须二次确认，启用无需确认。
- 导入与详情关系使用同一个人物/世界模糊搜索多选组件，已选对象显示为可移除标签。
- 详情关系变化立即保存；请求失败时恢复原选择。
