# 后台界面模板重构开发记录

## 完成内容

- 依据 `docs/UX` 的“档案编辑室 + 安静控制台”模板，统一为深墨侧栏、暖纸画布、暖白内容表面、编辑型衬线标题和砖红主操作色。
- 新增分组侧栏、桌面折叠、移动抽屉、顶部状态栏和 `Ctrl/Cmd + K` 页面命令导航；命令导航只查找现有页面，不伪装为跨人物或资料全文搜索。
- 统一页面面包屑、稳定路由标识、标题、说明和主要操作区域；动态详情页不会在路由标识中暴露具体 UUID。
- 把首页调整为“今日工作”，使用连续资源摘要、待确认事项、活动任务、最近人物和折叠系统状态组织真实数据。
- 登录与首次设置改为双区专注布局，明确本机事实源、唯一管理员和本机密码恢复边界。
- 统一用户可见名称：新建任务、资料库、学习中心、内容模板和系统中心。
- 修正 OpenViking 运行降级说明：新任务创建前不可用时改用 SQLite FTS5，已创建任务保持原检索方式。
- 保留现有接口、页面业务动作、轮询方式和服务端分层，没有修改数据模型或后端流程。

## 样式组织

- `app/assets/css/main.css` 只负责导入和既有通用控件入口。
- `app/assets/css/theme/tokens.css` 保存品牌令牌、Nuxt UI 语义映射、暗色令牌和基础无障碍规则。
- `app/assets/css/theme/shell.css` 保存侧栏、顶部栏、移动抽屉和命令导航样式。
- `app/assets/css/theme/content.css` 保存页面头部、状态带、章节、面板和日志列表样式。
- `app/assets/css/theme/authentication.css` 保存登录与首次设置页面样式。
- 组件视觉默认值通过 `app/app.config.ts` 调整，未把页面专属规则堆入公共入口文件。

## 验证结果

- Vitest：29 个测试文件、145 项测试全部通过。
- Playwright：首次设置、登录、页面命令导航、移动抽屉、人物与资料主流程、图文三格式导出和系统中心闭环通过。
- Nuxt 生产构建通过。
- 人工视觉检查覆盖 1440px 桌面端和 375px 移动端；移动页面无横向溢出，抽屉遮罩和过渡正常。
- `vue-tsc` 仍被工作区已有 TypeScript 7.0.2 与 vue-tsc 3.3.11 的导出兼容问题阻断：TypeScript 未导出 `./lib/tsc`。本轮未修改用户正在调整的依赖文件，生产构建和运行测试均通过。
