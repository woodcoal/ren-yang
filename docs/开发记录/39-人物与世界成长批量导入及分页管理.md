# 人物与世界成长批量导入及分页管理

## 1. 完成范围

- 人物反馈资料与世界资料均可直接批量导入成长；每份资料独立设置 1–5 分，评分映射为成长重要程度。
- 批量导入只提交来源 UUID、评分和共用适用范围；服务端重新读取当前资料正文和范围，整批在一个 SQLite 事务中创建。
- 单份资料正文超过成长既有 20000 字上限时整批拒绝，不截断、不产生部分结果。
- 成长结果默认每页 10 项，支持 5、10、20、50 项切换、全选本页和跨页选择。
- 成长支持批量启用、禁用、拒绝和永久删除；删除前必须二次确认，修订和证据依赖数据库级联清理。
- 成长支持逐条修改。修改建立新不可变修订、复制上一版证据快照并恢复为 `candidate`，旧修订不覆盖。
- 人工添加成长、资料导入和人物反馈资料添加均改为弹窗；长正文列表显示摘要，可按需展开完整内容。
- 人物反馈资料和世界成长资料列表默认每页 10 项，避免资料较多时持续拉长页面。

## 2. 接口

人物：

- `POST /api/v1/personas/{personaId}/growth/import`
- `PATCH /api/v1/personas/{personaId}/growth/{growthId}`
- `DELETE /api/v1/personas/{personaId}/growth`

世界：

- `POST /api/v1/worlds/{worldId}/growth/import`
- `PATCH /api/v1/worlds/{worldId}/growth/{growthId}`
- `DELETE /api/v1/worlds/{worldId}/growth`

控制器只解析共享 Schema 并调用 `LearningApplicationService`；应用服务只通过 `LearningRepository` 访问 SQLite。

## 3. 数据一致性

- 批量导入先完整核对全部资料归属和正文长度，再一次性创建成长、第一版修订、证据快照和审计事件。
- 修改成长在同一事务内写入新修订、复制证据并切换当前修订指针；状态恢复为待确认，避免未审核修改直接进入新任务。
- 批量删除先核对全部成长属于当前人物或世界，范围不完整时返回冲突且不删除任何记录。
- 删除成长不改变历史运行的上下文快照；SQLite 的 `learning_fts` 删除触发器同步移除当前检索记录。

## 4. 界面边界

- `GrowthRecordPanel.vue`：分页、选择和批量动作编排。
- `GrowthRecordList.vue`：当前页成长展示和逐条修改入口。
- `GrowthRecordEditorModal.vue`：新增与新修订表单。
- `GrowthSourceImportModal.vue`：资料批量选择、逐条评分和导入提交。
- 页面组件只负责调用接口与刷新工作区，子组件通过类型化事件表达操作意图。
