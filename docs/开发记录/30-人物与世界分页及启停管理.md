# 人物与世界分页及启停管理

## 目标

- 人物与世界管理列表对齐资料库的分页和批量状态交互。
- 禁用只约束后续新业务，不破坏对象、心智、关系和历史快照。
- 保持控制器、应用服务和仓储分层，控制器不直接访问数据库。

## 实现

- `worlds`、`personas` 增加默认值为 `1` 的 `is_enabled` 字段和布尔检查约束。
- 新增 `0002_persona_world_status.sql` 兼容迁移；旧人物、世界和人物所属世界关系原样保留，旧对象默认启用。
- 新增人物与世界分页接口，支持每页 5、10、20、50、100 项，默认 10；服务端修正越界页码并按更新时间、UUID 稳定排序。
- 新增单项及最多 100 项的批量状态接口。应用服务先验证并去重全部 UUID，仓储再用单条参数化 SQL 更新，避免部分成功。
- 人物与世界列表支持当前页勾选、全选、批量启用、确认后批量禁用、URL 分页和无文字图标详情按钮。
- 人物与世界详情支持单项启停；禁用必须二次确认，重新启用直接执行。
- 禁用人物不能创建新兴趣判断或图文任务。禁用世界后，关联人物仍可创建任务，但新任务不再检索或固定该世界的灵魂、成长和资料。
- 创作工作台只显示已启用且已有发布灵魂的人物。

## 验证

- 数据库测试覆盖空库迁移、旧人物和世界默认启用、关联保留及外键完整性。
- 应用服务测试覆盖分页默认值、稳定分页、越界修正、单项启停、批量去重和无效 UUID 原子失败。
- 生成测试覆盖禁用人物拒绝新任务，以及禁用世界从新任务上下文排除。
- 组件测试覆盖默认每页 10 项、5/10/20/50/100 选项、选择提示、批量启用、禁用二次确认和图标操作。
- `pnpm test`：36 个测试文件、180 个测试通过。
- `pnpm build`：Nuxt 客户端、服务端和 Nitro 生产构建通过。
- `pnpm typecheck`：工作区现有 `TypeScript 7.0.2` 未导出 `./lib/tsc`，与 `vue-tsc 3.3.11` 不兼容，在加载类型检查器阶段失败；本次未改动用户尚未提交的依赖版本。
