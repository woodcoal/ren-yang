# 人物重新蒸馏与列表摘要收敛

## 调整

- 人物和世界列表的介绍最多显示两行；修正基础列表样式覆盖 `line-clamp` 的级联问题。
- 人物和世界详情页顶部介绍统一限制为两行，完整内容仍由对应工作区承载。
- 灵魂编辑区的 AI 整理按钮改为纯图标，保留可访问名称与悬停说明。
- 人物灵魂区增加“重新蒸馏”图标，用户可填写本次聚焦方向并调整默认选中的已关联资料。
- 重新蒸馏固定发起时的当前灵魂版本和正文，继续使用资料覆盖与最终候选两个人工检查点。
- 最终确认在同一 SQLite 事务中校验当前灵魂基线，只为原人物发布新灵魂版本，不创建副本。

## 验证

- 基础组件、人物蒸馏应用、SQLite 仓储与迁移测试通过。
- `pnpm check` 通过：75 个测试文件、467 项测试、备份恢复验证及生产构建全部通过。
- `pnpm test:e2e` 通过：4 项核心浏览器闭环全部通过，包含原人物重新蒸馏并发布新灵魂版本。
- 列表与详情页两行截断回归测试通过：2 个组件测试文件、9 项测试及 `pnpm typecheck` 通过。
- 生产构建后直接用 Chromium 检查计算样式：列表介绍和世界详情页头部的 `-webkit-line-clamp` 均为 `2`，实际高度小于完整内容高度。
