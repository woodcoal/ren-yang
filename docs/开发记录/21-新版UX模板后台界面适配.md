# 新版 UX 模板后台界面适配开发记录

## 1. 实施范围

- 以 `docs/UX` 2026-08-30 版本的多页面原型、品牌规范和共享样式为只读设计基准。
- 保留现有 Nuxt 页面、`/api/v1` 接口、SQLite/OpenViking 数据边界、轮询机制和人工确认流程。
- 真实产品没有独立的 `/evaluations/[id]` 路由，评测用例继续位于学习中心和人物工作区；未为匹配静态原型而伪造后端能力。
- `docs/UX` 属于用户提供的设计源文件，本次没有修改，也没有纳入提交。

## 2. 设计系统调整

- 默认视觉由旧版暖纸档案风格改为雾白中性工作室，标题与正文统一使用系统无衬线字体。
- 新增雾白、暖砂、海盐、松岚四套 OKLch 语义主题；主题偏好保存到 `renyang-theme`，不会改变成功、警告和失败语义。
- 使用正式人物图形品牌标志和副标题“让它有个人样”，替换旧圆形“人”字占位标志。
- 页面最大内容宽度调整为 1240px，侧栏调整为 248px，顶部栏调整为 64px；圆角、边框和强调色按新版原型收敛。
- 公共样式继续拆分：基础令牌、应用壳、内容结构、数据表面、工作流、心智编辑和认证页面分别维护，未堆入单一 Vue 文件或 `main.css`。

## 3. 页面适配

### 3.1 应用壳与认证

- 侧栏和认证页使用统一品牌组件；折叠状态只保留可识别标志。
- 顶部栏加入主题选择器，保留任务状态和退出动作；后续按界面复核结果将主题入口收敛为随主题变色的图标，并移除与侧栏重复的页面搜索命令和管理员信息。
- 登录和首次设置继续使用深色边界说明区与浅色操作区，移除旧装饰圆形，强化本机数据和唯一管理员边界。
- 修复移动抽屉遮罩的点击范围：遮罩从侧栏右侧开始，不再被侧栏内容拦截。

### 3.2 列表与工作台

- 首页标题和说明调整为“先处理会影响后续创作的事”，资源摘要改为扁平连续状态带。
- 人物、世界、资料和任务记录从卡片墙改为响应式语义表格；窄屏下每行转换为带字段名的记录块。
- 列表页增加实际数据状态摘要、明确空状态和连续筛选表面，状态仍同时使用文字与颜色。
- 内容模板和生成设置改为“新版本编辑区 + 连续版本记录”，明确历史任务不会被后续修改追溯改写。

### 3.3 深度页面

- 新建任务和创建人物使用连续步骤条、单层编辑区和固定提交栏，明确任务或草稿提交前后的影响边界。
- 人物与世界工作区状态摘要改为扁平分隔条，标签页改为单一底线导航。
- 资料详情按“资料正文、可检索段落、使用关系、删除资料”分区，避免正文、关系和危险操作同时挤在一个长页面。
- 任务详情按“结果、创作内容、使用依据、反馈学习、运行设置”分区；运行状态使用全页唯一深色状态板。
- 等待规格确认的任务默认进入“创作内容”，避免用户自行寻找下一步操作。
- 学习中心显示反馈总数、待确认用途和评测用例数量，并固定说明 AI 分类只是建议。
- 页面标题保留面包屑和主标题，后续按界面复核结果移除面向开发者的 `ROUTE /xxx` 路由标识。

## 4. 文档与测试契约

- 更新 `docs/07-管理界面与交互.md` 的四主题决策。
- 更新 `docs/13-后台界面重设计需求.md` 的视觉方向、列表优先级和字体规则。
- 新增品牌与主题组件测试，验证正式标志、四个可见主题名称、根节点主题和本机偏好同步。
- 更新端到端测试以匹配当前自由章节灵魂模型和新版语义表格，不再依赖旧固定字段或卡片标题角色。

## 5. 验证结果

- 综合检查：`pnpm check` 在 `pnpm typecheck` 阶段被 `vue-tsc@3.3.11` 与用户当前引入的 `typescript@7.0.2` 兼容问题阻断，报错为 `ERR_PACKAGE_PATH_NOT_EXPORTED: Package subpath './lib/tsc' is not defined by typescript/package.json`；本次未修改用户的依赖配置和锁文件。
- TypeScript：`pnpm exec tsc -p .nuxt/tsconfig.json --noEmit` 通过。
- Vitest：34 个测试文件、157 项测试全部通过。
- Playwright：首次设置、登录、主题持久化、移动抽屉、资料、世界灵魂、人物灵魂、任务生成、三格式导出和系统中心闭环通过。
- Nuxt 生产构建：`pnpm run build` 通过。
- 人工视觉检查：登录页覆盖 1440×1000 和 375×812；端到端流程覆盖 390px 与 1280px，页面无横向溢出。
