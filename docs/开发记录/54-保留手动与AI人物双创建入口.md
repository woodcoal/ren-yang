# 保留手动与 AI 人物双创建入口

## 调整

- 人物列表同时提供“手动创建”和“AI 蒸馏创建”，不再强制所有新人物进入蒸馏流程。
- 手动创建直接保存用户输入的完整默认灵魂，可选世界与资料只建立关系，全程不调用 AI。
- AI 蒸馏继续使用资料覆盖和最终候选两个人工检查点，并支持从任务记录恢复。
- `/api/v2/personas` 明确保留手动创建，按 `snapshot.promptText` 原文发布初始灵魂；公共 API 不开放 AI 人物蒸馏。
- 人样 Skill 同步两种创建边界，避免外部 Agent 把手动创建误判为 AI 分析。

## 验证

- 人物列表组件测试覆盖手动原文创建和 AI 蒸馏创建。
- 公共 OpenAPI 单元测试确认手动创建不调用 AI。
- `pnpm check` 通过：75 个测试文件、464 项测试及生产构建全部通过。
- `pnpm test:e2e` 通过：4 项核心浏览器闭环全部通过。
