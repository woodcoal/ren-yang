# 资料来源元数据公共协作

## 完成范围

- 资料创建、修改和 TXT/Markdown 文件上传支持可选来源地址、作者或发言者、发表时间和原始来源键。
- 共享 Zod Schema 接受内部 Unix 毫秒和公共带时区 ISO 8601 时间，并统一转换为 SQLite 毫秒值。
- 领域记录、资料公开视图、内容应用服务和 SQLite 创建/替换映射完整保留四个来源字段。
- 修改资料时省略来源字段保留现值，显式 `null` 清除对应字段。
- 公共 OpenAPI 与人样 Skill 资料参考补齐 JSON、Multipart 字段、时间格式和同源键使用规则。
- 创建人物蒸馏运行时把来源元数据固定到输入快照，并优先使用 `originalSourceKey` 进行同源分组。

## 关键约束

- SQLite 继续保存资料及来源元数据的唯一业务事实；OpenViking 仍是可重建投影。
- 同一作品、访谈或事件的转载、节选和分段复用同一 `originalSourceKey`，避免虚增独立来源。
- 公共资料维护接口只负责导入和维护资料，不开放人物蒸馏运行权限。
- 来源字段均为可选；现有网页资料表单不需要为了空字段增加额外交互。

## 验证

- 资料持久化、人物蒸馏输入、公共 Schema 与 OpenAPI 基础测试通过：4 个文件、40 项测试。
- `pnpm typecheck` 通过。
- 完整门禁统一留到人物蒸馏全部阶段完成后执行。
