# 移除学习中心并闭合反馈修正链路开发记录

## 调整目标

删除没有独立业务闭环的学习中心和未接入执行器的回归用例，将反馈确认保留在来源任务，将人物长期变化保留在人物成长工作区；同时确保“只修正当前产物”的反馈正文真正进入本次重试。

## 完成内容

### 1. 收敛反馈入口

- 删除 `/feedback` 页面及侧栏“学习中心”入口；
- 首页待确认反馈改为逐条展示，并直接跳转对应任务详情；
- 反馈提交、AI 分类建议和人工用途确认继续由任务详情承担；
- 人物学习反馈继续原子创建默认 3 分且已启用的成长素材，之后仍需成长分析和人工发布。

### 2. 删除闲置回归用例

- 删除回归用例表单、共享 Schema、公开类型、领域记录和仓储方法；
- 删除 `GET/POST /api/v1/personas/{personaId}/evaluation-cases`；
- 新增 SQLite 迁移，物理删除 `evaluation_cases` 及其中未形成实际效果的数据；
- 不保留只有存储能力、没有执行、评分和结果消费链路的兼容代码。

### 3. 修复当前产物反馈

- 反馈确认后把原始反馈正文固定到 `execute_block` 任务载荷；
- 文字块把反馈追加到本次块要求，图片块把反馈追加到本次视觉主题；
- 反馈修正重试不修改已确认文档规格，但在尝试输入快照中保存反馈正文；
- 即使此前自动尝试次数已经耗尽，用户确认的反馈仍获得一次新的受控修正机会。

### 4. 保留反馈分类提示词

- 提示词目录中的 `feedback.classification` 仍由任务反馈分类服务实际调用；
- 系统不存在学习中心或回归评测专用提示词，因此不删除提示词目录中的运行依赖。

## 数据影响

迁移会永久删除未被实际执行链路消费的 `evaluation_cases` 表及现有记录。反馈事件、分类建议、确认历史、人物成长素材和已经发布的成长提示词不受影响。

- TypeScript 检查通过：`pnpm exec tsc -p .nuxt/tsconfig.json --noEmit`；
