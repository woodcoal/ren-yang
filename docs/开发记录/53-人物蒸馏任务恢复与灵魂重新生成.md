# 人物蒸馏任务恢复与灵魂重新生成

## 修复

- 人物蒸馏运行进入统一任务记录，执行阶段显示“执行中”，两个人工检查点显示“等待审核”。
- 人物创建前使用候选名称展示，点击任务进入原人物蒸馏工作区；最终确认后才关联人物详情。
- 页面切换不影响 SQLite 中的运行、输入、候选、证据和评测，用户可从任务记录继续处理。
- 无资料认知提取引用用户明确设定时，程序固定使用完整原文，避免模型改写引文造成无法定位。
- 外部资料引文继续严格逐字定位；非法输入标识或资料引文先触发一次模型结构修正，仍不合法时终止运行。
- 灵魂编辑区原 AI 整理图标改为明确的“重新生成”按钮，只回填当前编辑内容的整理结果，不自动发布。
