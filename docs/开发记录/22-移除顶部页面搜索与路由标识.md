# 移除顶部页面搜索与路由标识开发记录

## 1. 调整范围

- 移除顶部栏中的页面搜索入口、`Ctrl K` 快捷键和命令面板。
- 移除公共页面标题中的 `ROUTE /xxx` 路由标识。
- 保留侧栏导航、移动端导航按钮、面包屑、页面主标题、主题选择和系统状态入口。

## 2. 实现说明

- 删除顶部栏不再使用的搜索状态、筛选逻辑、键盘监听、弹窗结构和公共样式。
- 删除导航定义中仅供命令面板使用的说明字段和扁平导航列表。
- 页面路由上下文仅保留面包屑需要的导航分组，不再计算或返回路由代码。
- 更新后台界面需求和新版 UX 适配记录，使文档与当前界面一致。

## 3. 验证范围

- TypeScript：`pnpm exec tsc -p .nuxt/tsconfig.json --noEmit` 通过。
- Vitest：34 个测试文件、159 项测试全部通过；其中组件测试确认顶部栏不再存在页面搜索入口，页面标题保留面包屑且不再显示路由代码。
- Playwright：完整业务闭环通过，并在真实页面确认两个区域均不存在，移动导航和主题切换仍可使用。
- Nuxt 生产构建：`pnpm run build` 通过。
