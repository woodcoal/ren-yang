# 资料批量启用与操作栏精简

## 目标

- 在资料列表现有批量禁用基础上增加批量启用。
- 缩小批量按钮并移除按钮边框。
- 未选择资料时隐藏选择数量，精简批量操作行视觉样式。

## 实现

- 当前页启用和禁用资料均可勾选，表头复选框选择当前页全部资料。
- “批量启用”只提交已选禁用资料，直接执行并刷新列表。
- “批量禁用”只提交已选启用资料，继续要求用户二次确认。
- 两个批量按钮使用 `xs` 和 `ghost` 样式。
- 操作行移除背景、圆角和边框；无选择时保留操作按钮并隐藏数量文字。
- 资料行右侧用带无障碍名称的右箭头图标进入详情。
- 切换分页或状态修改成功后清空当前页选择。
