# 世界与人物快速初始化

## 决策

- 世界和人物列表的创建入口统一为单自然语言弹窗。
- 人物初始化固定为原创，不关联世界或资料；世界初始化不关联资料。
- AI 不可用或结构校验失败时不创建对象，保留弹窗输入。
- 创建成功后自动进入详情，初始草稿不自动发布。

## 实现

- `QuickCreateSubjectModal` 只负责自然语言输入、共享 Schema 校验和提交事件。
- 人物列表复用现有人物草稿接口，再调用人物创建接口。
- 世界新增 `POST /api/v1/worlds/draft`，生成名称、后台摘要、灵魂章节和运行摘要；控制器只调用生成应用服务。
- 两个列表页都按“草稿生成 → 业务创建 → 详情导航”顺序编排，不引入服务跨层调用。
- `/personas/new` 不再展示复杂表单，只转回人物列表。

## 验证

- 世界草稿生成必须返回完整名称、摘要和灵魂快照，且不落库。
- 弹窗只提交自然语言，错误状态下保留原文。
- `pnpm vitest run tests/components/subject-list-creation.test.ts --reporter=verbose`：1 个测试文件、2 个测试通过。
- `pnpm test`：36 个测试文件、174 个测试通过。
- `pnpm build`：Nuxt 客户端、服务端与 Nitro 生产构建通过。
- `pnpm typecheck`：在执行源码检查前因当前工作区未提交的 `TypeScript 7.0.2` 与 `vue-tsc 3.3.11` 不兼容而终止；本次不修改该独立依赖变更。
