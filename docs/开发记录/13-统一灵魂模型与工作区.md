# 统一灵魂模型与工作区开发记录

## 1. 本阶段目标

把人物固定八字段和世界单正文改为统一灵魂模型，并让后台真实使用自由章节、运行摘要、唯一草稿和不可变发布版本。

## 2. 已完成内容

### 2.1 数据与领域

- 新增 `SoulChapter`、`SoulSnapshot`、`SoulDraftRecord`、`SoulVersionRecord`；
- 新增 `soul_drafts` 和 `soul_versions`，删除 `persona_versions`、`world_versions`；
- 世界和人物当前指针改为 `active_soul_version_id`；
- 章节支持增加、改名、删除、排序和核心章节标记；
- 运行摘要与完整章节分开保存，提示词只读取已发布运行摘要；
- 发布时使用 UTF-8 字节保守估算 Token，世界限制 2500、人物限制 3500；
- 历史恢复改为复制成草稿，不再直接切换当前版本指针；
- 迁移 `0007_unified_soul_model.sql` 清空业务数据并重建统一版本外键，保留管理员凭据。

### 2.2 分层与接口

- 新增 `SoulApplicationService`，控制器只调用应用服务；
- 新增 `SoulRepository`、`TokenCounter` 端口；
- `SqliteContentRepository` 同时实现内容事实源和灵魂事实源；
- 新增世界、人物灵魂查询、草稿保存、草稿删除、发布、从历史建立草稿接口；
- 删除旧候选版本创建、发布和直接回滚写接口；
- `ContentApplicationService` 只负责人物、世界元数据和资料管理，灵魂写操作不再混入内容服务。

### 2.3 后台界面

- 人物和世界创建表单不再显示固定八字段或单一世界正文；
- 新增共用自由章节编辑器和灵魂工作区；
- 人物工作区改为“概览、灵魂、成长、记忆、世界与资料”标签；
- 世界工作区改为“概览、灵魂、成长、世界资料、人物与管理”标签；
- 当前已发布灵魂和未发布草稿并列说明；
- 历史版本只允许复制为修改稿；
- 公共工作区样式独立放在 `app/assets/css/theme/mind.css`。

## 3. 数据迁移影响

本迁移按用户明确授权清空以下业务数据：人物、世界、资料、生成运行、产物、反馈、评测、成长、记忆、OpenViking 本地投影状态和审计事件。管理员凭据保留。OpenViking 远端内容不在本阶段直接删除，后续由 SQLite 当前事实执行重建或清理。

## 4. 验证记录

- 基线：29 个测试文件、145 个测试通过；
- 新迁移在全新临时 SQLite 数据库执行成功；
- 临时库只存在 `soul_drafts`、`soul_versions`，不存在旧版本表；
- `PRAGMA foreign_key_check` 无违规；
- 内容管理、灵魂发布、历史复制、版本删除、提示词和组件目标测试通过；
- 生产构建通过；
- `nuxt typecheck` 受用户现有 TypeScript 7.0.2 与 vue-tsc 3.3.11 不兼容阻断，`tsc -p .nuxt/tsconfig.json --noEmit` 通过。此问题不是本阶段引入，未通过关闭更多检查规避。
