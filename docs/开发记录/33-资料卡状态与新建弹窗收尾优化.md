# 资料卡状态与新建弹窗收尾优化开发记录

日期：2026-08-30

## 目标

- 人物和世界快速创建时保留原页面的视觉连续性，不让等待状态看起来像跳转到新页面。
- 人物和世界的资料卡支持整卡进入资料详情，并能直接启用或禁用资料。
- 禁用资料前必须二次确认，并明确这是影响所有人物和世界的全局状态。
- 新资料保存成功后自动关闭弹窗；再次新建时必须展示空白表单。

## 实现内容

### 创建等待遮罩

`QuickCreateSubjectModal` 保留 `Teleport` 与 `z-[9999]` 最高层遮罩，将近乎不透明背景调整为半透明背景 `bg-default/55` 和 `backdrop-blur-md`。用户等待 AI 初始化时仍能辨认原页面结构，同时不能误操作页面内容。

### 资料卡操作

新增 `SubjectSourceCard`，把单项资料展示从统一管理组件中拆出：

- 整张卡片提供资料详情链接；
- 状态、用途和正文摘要继续可见；
- 启用、禁用和解除关联使用独立图标按钮，不触发详情跳转；
- 已启用资料点击禁用后先进入确认弹窗；已禁用资料可直接启用。

状态修改继续调用既有 `PATCH /api/v1/sources/{sourceId}/status`。人物和世界详情页只负责调用接口及刷新页面数据，没有新增控制器、服务层或数据层逻辑。

### 新建弹窗生命周期

`SubjectSourceManager` 在提交文本或文件资料时记录当前创建请求。父页面加载状态从进行中恢复后：

- 没有错误：关闭新建弹窗，并销毁旧表单状态；
- 存在错误：保留弹窗，允许用户检查或重试；
- 每次主动打开新建弹窗前：创建新的 `SourceImportForm` 实例，确保输入为空。

创建请求进行期间禁止关闭弹窗，避免用户误认为请求已经取消。
