# 启动实例锁错误诊断

## 现象

开发服务完成 Vite 与 Nitro 构建后，只输出“应用运行时初始化失败，进程已终止”，无法判断失败原因。

## 根因

- 同一项目已有开发进程占用 3000 端口并持有 `data/.application.lock`。
- 第二个进程被数据目录单实例保护拒绝，避免多个进程同时写入同一个 SQLite 数据库。
- 启动插件捕获异常后丢弃了原始错误消息，因此终端只显示通用错误。
- `Nuxt Icon server bundle mode is set to local` 是正常提示，与故障无关。

## 调整

- 保留数据目录单实例保护，不允许第二个进程绕过锁。
- 启动失败时只输出异常消息，不输出异常堆栈或配置内容。
- 无可用异常消息时回退为“未知错误”。

## 验证

- 使用独立临时数据目录启动开发服务：成功。
- 使用已被现有进程持有的数据目录启动第二个开发服务：明确输出“应用运行时初始化失败：该数据目录已有运行中的人样进程”。
- 现有开发进程与业务数据未停止、未删除、未修改。
