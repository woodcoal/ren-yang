# 修复无资料人物蒸馏分类失败

## 问题

无资料人物蒸馏仍调用资料分类模型。真实模型可能在空数组输入下虚构一项分类，严格的一致性校验随后以“人物蒸馏资料分类与本次运行输入不一致”终止运行。

## 修复

- 无资料输入时由应用服务直接保存空分类和零覆盖快照，不调用资料分类模型。
- 运行继续进入资料覆盖人工确认，后续认知提取、灵魂综合和候选评测保持不变。
- 有资料输入时继续执行资料分类模型，并严格拒绝缺项、额外标识和重复分类。
- 增加模拟模型为空输入虚构分类的回归测试，确保该输出不会再进入执行路径。

## 验证

- `pnpm exec vitest run tests/integration/persona-distillation-application-service.test.ts`：1 个测试文件、3 项测试通过。
- `pnpm typecheck` 通过。
