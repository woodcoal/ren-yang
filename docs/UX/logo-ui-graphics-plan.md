- 加载动效只保留规则定义，本轮不制作视频、GIF 或 Lottie 文件。

## 2. 设计目标

1. **一眼识别人形，再识别“人”字**：LOGO 不再承载档案、版本等第二层隐喻，先把人物轮廓与品牌名称建立直接联系。
2. **小尺寸可用**：符号在 `16px` favicon、`24px` 图标和 `34px` 侧栏标志中仍能辨识。
3. **主题无关**：形状不能依赖某一种强调色；黑白、反白和四主题版本都应成立。
4. **产品化而非展示化**：所有图形都需要对应真实 UI 场景，不创建无用途的装饰插画。
5. **统一但不泛滥**：LOGO 使用实心圆与圆端宽笔画，功能图标继续使用线性几何；两者保持清晰的层级区别。

## 3. 最终核心概念：人形字标

### 3.1 标志符号

以站立人物和汉字“人”的共同轮廓为核心，只保留圆形头部与两条向下张开的宽笔画：

- 独立圆形首先建立清楚的头部识别，避免标志只像抽象折线。
- 两条等重圆端宽笔画在顶部自然汇合、向下稳定张开，同时形成身体和“人”字轮廓。
- 默认版本使用深色左笔画与品牌色头部／右笔画；单色和反白版本统一笔画颜色。
- 标志不再叠加档案页、版本、机器人、对话气泡或 AI 星芒等隐喻。
- favicon 使用深色圆角底、反白身体和品牌色头部，确保 `16px` 下仍能辨识为人物。

### 3.2 中文标准字

- 主标准字为“人样”，使用可信的中文无衬线粗体，不再用手绘线段模拟完整汉字。
- 网页原型使用 `Noto Sans SC`、`Microsoft YaHei`、`PingFang SC` 的有序回退；正式印刷母版可在确认字体授权后转为轮廓。
- 标准字采用紧凑字距和稳定粗细，不对“样”字做破坏可读性的变形。
- 默认不增加英文品牌名，避免未确认的音译或对外名称进入产品。

### 3.3 组合方式

| 组合 | 内容 | 主要使用位置 |
| --- | --- | --- |
| 主符号 | 人形字标 | favicon、应用图标、折叠侧栏、默认头像 |
| 横向主标 | 符号 + 人样 | 登录页、启动页、帮助页、品牌板 |
| 产品组合 | 符号 + 人样 + Agents, with a human touch. | 展开侧栏、首次设置、系统信息 |
| 纯标准字 | 人样 | 内容署名、窄横幅、低高度区域 |
| 单色反白 | 全白或全深色 | 深色侧栏、打印、不可使用主题色的场景 |

## 4. 色彩与主题适配

### 4.1 默认品牌版本

- 默认浅色背景使用深色标志，强调色只用于主符号或一个局部识别面。
- 默认强调色：`oklch(47% 0.11 28)`。
- 默认深色：`oklch(21% 0.018 255)`。
- 深色侧栏优先使用反白标志；只有 `34px` 以上的实心应用图标可使用主题强调色底。

### 4.2 四主题规则

- `mist`：朱红强调 + 石墨标志。
- `sand`：低饱和砖红强调 + 暖墨标志。
- `ocean`：钢蓝强调 + 深海标志。
- `sage`：深青强调 + 墨绿标志。
- 成功、警告和失败色永远不用于品牌 LOGO，避免品牌与状态语义混淆。
- 标志轮廓、留白和比例在各主题中完全不变，只替换语义颜色令牌。

## 5. UI 图形体系范围

### 5.1 品牌应用图形

- favicon：`16、32px` 验证尺寸。
- Web App 图标：`192、512px`。
- iOS 风格触控图标：`180px`。
- 侧栏展开／折叠标志：`34px` 与 `24px`。
- 默认人物头像：未设置图片时使用人物名字首字；人物详情支持上传 PNG、JPEG、WebP，或根据当前人物灵魂生成 1:1 头像。
- 加载标志：仅允许头部与身体做一次轻微聚合，不做无限旋转星芒。

### 5.2 实体图形

为核心对象建立 8 个可复用实体图形：

1. 人物
2. 世界
3. 资料
4. 任务
5. 反馈
6. 评测
7. 模板
8. 生成设置

实体图形用于空状态、对象标题和选择器，不与普通按钮图标混用。

### 5.3 功能图标

保留现有 `24×24` 线性体系并统一规范：

- 基准描边：`1.6px`；小尺寸可提高至 `1.75px`。
- 端点与连接：圆端、圆连接。
- 默认尺寸：导航 `18px`、普通操作 `18px`、重点状态 `22px`。
- 只使用单色 `currentColor`，不在 SVG 内写死主题颜色。
- 每个图标只表达一个动作，不用同一图标同时表示对象和状态。
- 优先补齐：发布、回滚、锁定版本、人工确认、引用来源、同步、重试、归档、恢复、冲突、候选状态。

### 5.4 状态符号

状态必须同时依赖形状和文字，不只依赖颜色：

| 状态 | 图形 | 说明 |
| --- | --- | --- |
| 已完成 | 实心圆内勾 | 已产生确定结果 |
| 进行中 | 缺口圆环 | 正在执行或等待轮询 |
| 待确认 | 菱形内点 | 需要人工判断 |
| 警告 | 圆角三角内短线 | 可继续但存在风险 |
| 失败 | 八边形内叉 | 操作失败或发布受阻 |
| 候选／目标态 | 双层方框 | 尚未生效或需要后端支持 |
| 已锁定 | 闭合锁形 | 历史上下文不可回写 |

### 5.5 空状态图形

只建立 4 个模块化场景，不为每个页面单独画插画：

1. **尚未建立人物**：主符号与一张空白人物卡。
2. **尚无任务结果**：三阶段轨道与未填充内容段落。
3. **尚无资料／世界关联**：两个未连接的实体图形。
4. **同步或检索不可用**：本地档案完整、远端节点断开。

规则：单个场景最多使用一种强调色；不画拟人角色，不使用大面积背景纹理，不在普通有数据页面展示。

## 6. 关键尺寸规范

| 项目 | 建议规格 |
| --- | --- |
| LOGO 主构图网格 | `24×24` 基准网格 |
| 符号安全留白 | 不小于符号宽度的 `25%` |
| 符号最小显示 | 屏幕 `16px`；印刷 `6mm` |
| 横向主标最小高度 | 屏幕 `24px` |
| 侧栏标志 | 展开 `34px`；折叠 `24–28px` |
| 功能图标视口 | `24×24` |
| 功能图标点击目标 | 不小于 `44×44px` |
| 实体图形 | `32、48、64px` 三档 |
| 空状态图形 | 最大约 `160×120px` |
